## Level 1 Concepts

### print()
- Displays output to the screen
- Example : print("Hello World")

### input()
- Gets user input as a string
- Example : name = input("What is your name? ")

### if / elif / else
- Conditional logic
- Example :
  if age >= 18:
      print("adult")
  else:
      print("minor")

### int() / float()
- Converts string to number
- Example : age = int(input("Enter age: "))
