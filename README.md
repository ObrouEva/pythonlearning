# Python Cybersecurity Learning Journey

## About This Repo

This repository documents my **complete Python learning journey**, focused on cybersecurity applications. Every project built here is a real tool with a real security use case.

## Goal

Become a professional Python developer specialized in cybersecurity — capable of building my own security tools, automating tasks, and thinking like a real security engineer.

## My Learning Methodology

- **Active learning only** - Learn by building, not watching tutorials
- **One concept at a time** - Master depth before moving on  
- **Every concept through real projects** - Theory applied immediately
- **Code review & refactoring** - Improve code after each project
- **70% mastery requirement** - Pass mini exam before progressing

## Project Structure

Each project follows the same pattern:

```

├── step_2.py          ← Add features
├── step_3.py
├── step_4.py
├── step_5.py
├── refactoring_v1.py  ← Optimize & refactor
├── refactoring_v2.py
├── refactoring_v3.py
├── refactoring_v4.py
├── refactoring_v5.py

```
